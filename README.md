# Local Turístico — Landing Page

Landing page de turismo desenvolvida com **HTML** e **CSS**, como desafio da Rocketseat. A página apresenta destinos em Busan (Coreia do Sul), com imagens, textos descritivos e um layout organizado e visualmente agradável.

## Objetivo

Praticar:

- Estruturação semântica em HTML
- Estilização e layout com CSS
- Organização de conteúdo (hero, seções de destinos e texto final)

## Tecnologias

- HTML5
- CSS3
- Google Fonts (`Asap` e `Open Sans`)

## Como visualizar

Abra o arquivo `index.html` no navegador ou use uma extensão de live server no editor.

```bash
# opcional: servir localmente com Python
python -m http.server 5500
```

Depois acesse `http://localhost:5500`.

## Estrutura do projeto

```text
rocketseat-Local-Turistico/
├── index.html          # Estrutura da página
├── style.css           # Estilos
├── images/
│   ├── image.png       # Imagem principal (hero)
│   ├── image-2.png     # Templo Haedong Yonggungsa
│   ├── image-3.png     # Templo Beomeo-sa
│   └── image-4.png     # Parque Yongdusan
└── README.md
```

## Conteúdo da página

1. **Hero** — introdução à viagem e destaque para Busan  
2. **Destinos** — três pontos turísticos:
   - Templo Haedong Yonggungsa
   - Templo Beomeo-sa
   - Parque Yongdusan
3. **Encerramento** — texto sobre a cidade e a experiência cultural
